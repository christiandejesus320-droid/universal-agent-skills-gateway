# Own luxury digital design system / Sistema propio de diseño digital de lujo

Read this reference only for branding, product UI, landing pages, immersive web, portfolio, campaign, 3D or motion work. It is an original synthesis, not a reproduction of any studio's identity, copy or assets.

## Design thesis / Tesis de diseño

Create quiet authority: a clear mission, an intentional visual voice, generous space, precise typography, meaningful motion and technology that serves the story. Luxury is not decoration or darkness; it is control, relevance, material quality and confidence in what is omitted.

Crea autoridad silenciosa: una misión clara, una voz visual intencional, aire generoso, tipografía precisa, motion con significado y tecnología al servicio de la historia. El lujo no es decoración ni oscuridad; es control, relevancia, calidad material y confianza en lo que se omite.

## Brand direction / Dirección de marca

Start with a one-sentence mission, audience tension, promise, proof and boundary. Select one visual territory such as editorial precision, cinematic technology, tactile craft, quiet modernism or controlled surrealism. Do not combine territories without naming the reason.

Empieza con misión, tensión de audiencia, promesa, prueba y límite en una frase cada una. Selecciona un territorio como precisión editorial, tecnología cinematográfica, oficio táctil, modernismo silencioso o surrealismo controlado. No combines territorios sin explicar por qué.

## Tokens / Tokens

Use a restrained palette with semantic roles rather than decorative colors. Default OLED surfaces: `#000000`, `#09090B`, `#111113`, `#18181B`, `#27272A`. Text: `#FAFAFA`, `#D4D4D8`, `#A1A1AA`. One accent is allowed and must carry meaning. Define contrast, light variant, dark variant, disabled treatment and focus ring before adding shades.

Use an 8px rhythm for layout (`8, 16, 24, 32, 48, 64`) and 4px only for compact internal spacing. Use a 12-column grid on desktop, fluid clamps for type and spacing, and a readable max-width. Avoid excessive pills; use 0–4px radii for editorial or brutalist work and 8–12px only when the product language needs softer controls.

Typography is structural. Choose one display voice and one reading voice, define optical sizes, line height, measure, weight and fallback. Do not use a fashionable font without testing numerals, accents, loading behavior and long-form readability.

Motion tokens: `ease-out` for entry, `ease-in-out` for state transition, spring only when physical feedback adds meaning. Establish duration tiers: 120–180ms micro, 240–360ms component, 500–900ms scene. Respect `prefers-reduced-motion`, preserve state communication without animation and avoid scroll hijacking.

## Composition / Composición

Use one dominant gesture per viewport: a typographic statement, a product image, a material surface, an interaction or a deliberate empty field. Build a rhythm of reveal, orientation, proof and invitation. White space is an active component. Every decorative element must justify hierarchy, mood or wayfinding.

## Interaction and product UI / Interacción y UI de producto

For operate-mode interfaces, clarity outranks spectacle. Define navigation, command surface, primary action, secondary action, status, empty state, loading, error, recovery and success before polishing. Keep enterprise rails at 260px only when navigation density requires it; otherwise let the content breathe.

Buttons need semantic variants, visible focus, keyboard behavior, target sizing, pending behavior, disabled explanation and error recovery. Never communicate critical meaning by color alone. Motion may guide attention, but cannot be required to complete the task.

## Immersive, 3D and canvas / Inmersivo, 3D y canvas

Use 3D when material, space, scale or transformation is part of the message. Define camera intent, interaction model, fallback poster, loading budget, device tier, frame budget, reduced-motion alternative and keyboard or pointer equivalent. Prefer progressive enhancement over making the entire page depend on WebGL.

## Evaluation rubric / Rúbrica de evaluación

Score each dimension from 0 to 4 with evidence, not vibes: mission clarity, visual hierarchy, typography, distinctiveness, interaction quality, motion purpose, accessibility, responsive behavior, performance, technical resilience and maintainability. A high score in visual novelty cannot compensate for a failure in usability or accessibility.

## Catalog entry / Entrada de catálogo

For each reusable pattern record: `id`, `problem`, `mode`, `audience`, `intent`, `visual_territory`, `tokens`, `states`, `responsive`, `accessibility`, `performance_budget`, `avoid_when`, `example`, `evidence` and `tags`. Search by user problem and intent before searching by aesthetic label.

## Anti-patterns / Antipatrones

Do not imitate a named studio, reproduce copyrighted work, add gratuitous WebGL, use animation as decoration, hide content behind a cinematic intro, sacrifice contrast for mood, ship an untested font, use a rating as truth, or add visual effects that increase cost without improving comprehension.

## Delivery checklist / Checklist de entrega

Before delivery, confirm the mission, audience, hierarchy, type, palette, spacing, states, keyboard path, contrast, reduced motion, responsive behavior, loading and error recovery, performance budget, asset rights, maintenance path and evidence. Stop when the agreed acceptance criteria pass.

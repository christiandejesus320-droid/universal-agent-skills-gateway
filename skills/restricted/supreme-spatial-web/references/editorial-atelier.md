# Editorial Spatial Atelier / Atelier editorial espacial

Esta referencia convierte la dirección de agencias de experiencias digitales en decisiones de trabajo. Active Theory describe su práctica como una combinación de historia, arte y tecnología con énfasis en calidad y rendimiento; Codrops documenta a Lusion como una práctica de storytelling web, branding y motion 3D. Se estudian esas relaciones, no sus identidades.

## Story before spectacle / Historia antes que espectáculo

La página debe tener una pregunta, una escena y una consecuencia. Si el shader no cambia la comprensión, se elimina. Si el video no prueba el trabajo, se convierte en poster o se quita.

```text
what is this
  → why should I look
  → what changed
  → what can I control
  → what remains true without the effect
```

## Viewport rhythm / Ritmo de viewport

Un viewport puede estar dominado por un objeto, una frase, una demostración o un vacío. No llenar cada superficie. Usar una proporción de lectura definida y reservar espacio para la obra.

## Interaction grammar / Gramática de interacción

| Acción | Respuesta adecuada |
| --- | --- |
| Cursor entra | El objeto responde ligeramente; no debe perseguir ni saltar. |
| Scroll | La escena avanza o revela una relación; debe poder invertirse. |
| Selección | Cambia el medio o el estado con continuidad y etiqueta. |
| Play | El sonido o video empieza con estado visible. |
| Error | La experiencia conserva una versión comprensible y ofrece salida. |

## Luxury without generic AI / Lujo sin IA genérica

Evitar glow azul, gradientes sin material, glassmorphism repetido, blobs abstractos, títulos con claims grandiosos y grids de tarjetas iguales. El lujo silencioso se construye con márgenes, tipografía, escala, contraste, detalle de material y ausencia de ruido.

## Case-study discipline / Disciplina de case study

Para cada escena documentar:

```yaml
intent: what the scene communicates
material: what surface or light model is used
motion: what causes the change
input: how the visitor controls it
fallback: what remains without GPU or video
proof: what was measured or verified
```
